# Third-party software

LED Control vendors source from [ORSSerialPort](https://github.com/armadsen/ORSSerialPort)
2.1.0, copyright Andrew R. Madsen, under the MIT License. The vendored copy has
a compatibility update for the current IOKit main-port API. The complete
license is included at `ORSSerialPort/LICENSE`.

The Arduino firmware uses [FastLED](https://github.com/FastLED/FastLED), which
is installed separately through the Arduino Library Manager and is not
redistributed in this repository.
